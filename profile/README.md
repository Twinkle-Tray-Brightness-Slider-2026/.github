# Project Overview

Twinkle Tray is a Windows utility that provides convenient brightness controls for multiple monitors directly from the system tray. It is designed for Windows 10 and Windows 11 and can control compatible external displays that Windows does not manage through its standard brightness controls.

The application adds a brightness flyout with individual sliders for connected displays. Users can adjust monitors independently or manage multiple displays together.

Twinkle Tray can also integrate with Windows personalization settings, providing an interface designed to match the desktop environment.

---

# Monitor Brightness & Multiple Displays

Twinkle Tray provides individual brightness sliders for compatible monitors.

Users can adjust brightness from the Windows system tray without opening each monitor's hardware controls. Multiple displays can be managed from the same brightness panel.

The application can also normalize brightness levels across different monitors, which can be useful when working with displays that have different default brightness characteristics.

---

# DDC/CI, WMI & Display Control

Twinkle Tray communicates with compatible displays using technologies including DDC/CI and WMI.

DDC/CI allows supported external monitors to receive commands such as brightness and other display-control settings directly from Windows.

Compatibility depends on the monitor and connection method. Some VGA/DVI connections and certain USB, Thunderbolt, or Surface docking configurations may not provide the required display-control functionality.

---

# Hotkeys, Profiles & Automation

Twinkle Tray supports keyboard shortcuts for adjusting the brightness of individual displays or multiple monitors.

Brightness can also be automatically adjusted according to the time of day or when the computer has been idle.

Profiles can be configured for different display setups and brightness requirements, while the application can start automatically with Windows.

# 2026 Updates

The 2026 development cycle introduced several improvements and experimental features.

The **v1.18.0 beta** series added support for ambient-light sensors, including compatible built-in Windows sensors and supported external Yocto light sensors. It also improved monitor detection, brightness restoration, startup behavior, localization, and multi-monitor handling.

The **v1.18.0-beta2** release additionally introduced optional software brightness control using the display gamma ramp for compatible displays that do not provide DDC/CI or WMI brightness controls.

As of September 2026, v1.18.0 remains a **beta/pre-release**, while the latest stable release listed by the project is **v1.17.2**.

# Command Line & Automation

Twinkle Tray supports command-line arguments for changing monitor brightness from scripts or other applications.

Supported commands can select a monitor, set an absolute brightness value, apply a brightness offset, control all displays, list connected displays, and send supported DDC/CI VCP commands.

This allows brightness control to be integrated into custom Windows automation workflows.
